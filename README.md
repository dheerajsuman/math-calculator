# Advanced Mathematical Calculator

A feature-rich, web-based mathematical calculator built with HTML, CSS, and JavaScript.

## Features

### 🧮 Basic Calculator
- Standard arithmetic operations (+, -, *, /, %)
- Real-time calculation display
- Calculation history
- Keyboard support

### 🔬 Scientific Calculator
- **Trigonometric Functions**: sin, cos, tan
- **Logarithmic Functions**: log (base 10), ln (natural log)
- **Power Operations**: x², x³, x^n
- **Other Functions**: square root, factorial, absolute value
- **Constants**: π (pi), e (Euler's number)

### 🔄 Unit Converters
- **Temperature**: Celsius ↔ Fahrenheit
- **Length**: Meters ↔ Feet
- **Weight**: Kilograms ↔ Pounds
- Real-time conversion
- Reset functionality

### 📊 Function Graphing
- Plot mathematical functions
- Supports various mathematical operations
- Visual grid and axes
- Real-time rendering

## How to Use

1. **Basic Calculator**: Enter numbers and operators, press `=` to calculate
2. **Scientific Calculator**: Use additional functions like sin, cos, sqrt, etc.
3. **Unit Converters**: Enter a value in any field, conversion happens automatically
4. **Graph Plotter**: Enter a formula (e.g., `x^2`, `sin(x)`, `sqrt(x)`) and click "Plot Graph"

## Keyboard Shortcuts (Basic Mode)
- **Numbers**: 0-9
- **Operators**: +, -, *, /
- **Decimal**: .
- **Calculate**: Enter
- **Delete**: Backspace
- **Clear**: Escape

## Supported Math Functions
- `sin(x)`, `cos(x)`, `tan(x)` - Trigonometric functions
- `sqrt(x)` - Square root
- `log(x)` - Base 10 logarithm
- `ln(x)` - Natural logarithm
- `abs(x)` - Absolute value
- `x^2`, `x^3`, `x^n` - Power operations
- `1/x` - Reciprocal
- `n!` - Factorial
- `ceil(x)`, `floor(x)`, `round(x)` - Rounding functions

## Technical Stack
- **HTML5**: Semantic markup
- **CSS3**: Modern styling with gradients and flexbox
- **JavaScript (Vanilla)**: No dependencies required

## Responsive Design

Simply open `index.html` in a web browser. No installation or dependencies required.
